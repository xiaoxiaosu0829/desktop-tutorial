========================================================
 网络游戏账号交易版权监测系统 V1.1
 使用说明
========================================================

一、这是什么
--------------------------------------------------------
面向游戏版权方 / 发行商 / 渠道合规团队的账号交易侵权线索监测平台。
参考交易猫、螃蟹等账号交易平台的信息结构建模，覆盖：
  挂售发现 → 作品归属 → 授权核对 → 风险判定 → 处置闭环 → 周期报告

当前版本为可运行框架，内置的是【合成演示数据】，
所有商品、店铺、链接均为虚构，不连接任何真实交易平台。

二、运行环境
--------------------------------------------------------
  Windows 10 / 11
  Node.js 22.5 或更高版本（内置 node:sqlite，无需额外数据库）
  现代浏览器（Edge / Chrome）

检查是否已安装 Node：打开命令行执行  node -v

三、怎么启动
--------------------------------------------------------
  方式一（推荐）：双击  启动.bat
      · 首次运行会自动安装依赖（1-3 分钟），之后秒开
      · 浏览器自动打开 http://127.0.0.1:8787
      · 关闭命令行窗口即停止服务

  方式二（开发）：双击  开发模式.bat
      · 前端 http://127.0.0.1:5173（热更新）
      · 后端 http://127.0.0.1:8787

  方式三（命令行）：
      npm install
      npm run build
      npm start

四、登录与注册
--------------------------------------------------------
  ★ 默认管理员账号（首次启动自动创建）
        用户名：admin
        密码  ：Admin@12345

  【登录方式】
    1. 打开 http://127.0.0.1:8787
    2. 输入账号密码 → 点「登录」
    3. 登录成功后进入监测控制台

  【每次进入都要登录】
    默认情况下，登录状态只在当前浏览器会话内有效：
      · 关闭浏览器（或所有标签页）后再次打开，需要重新登录
      · 刷新页面无需重复登录

  【记住账号密码（7 天免登录）】
    登录页勾选「记住账号密码」后：
      · 7 天内再次打开网页，自动进入控制台，无需输入账号密码
      · 超过 7 天没有登录，系统会自动失效，必须重新输入账号密码
      · 浏览器会自动回填上次的用户名，密码始终不会被保存到本地
      · 不勾选则不会记住，每次关闭浏览器后都需重新登录

    什么时候需要重新登录：
      · 关闭浏览器且未勾选「记住账号密码」
      · 距离上次登录已超过 7 天
      · 主动点击「退出」
      · 管理员停用了该账号

  【注册新账号】
    1. 在登录页点「注册」标签
    2. 填写用户名（3-20 位，中英文/数字/下划线）、显示名（可选）
    3. 密码至少 8 位，需二次确认
    4. 点「注册并登录」，注册成功后自动进入控制台
    · 系统允许自助注册；第一个注册的账号自动成为管理员

  【右上角账号区】
    进入控制台后，界面右上角显示：
      · 当前账号的头像首字与显示名
      · 角色，以及「免登录剩 N 天」（勾选记住时为 7 天倒计时）
      · 「退出」按钮，点击即退出并回到登录页

  安全说明：
    · 密码用 scrypt 加盐派生后存储，数据库里看不到明文
    · 会话走 HttpOnly Cookie，前端脚本读不到凭证
    · 同一 IP + 账号连续输错 5 次，锁定 5 分钟
    · 除登录/注册/健康检查外，所有接口都需要登录才能访问

  ? 正式部署前请务必修改默认管理员密码（当前版本改密需直接操作数据库，
    或注册新账号后停用 admin；细粒度权限与改密界面规划在 V1.1）

五、界面导航
--------------------------------------------------------
  总览看板  — 线索总量、高风险、处理进度、7 日趋势、作品排行
  商品线索  — 筛选 / 分页 / 点开看规则命中与原始快照
  风险预警  — 新建 → 处理中 → 已处理 / 误报
  监测任务  — 新建任务、立即巡检、查看巡检日志
  版权与授权 — 作品版权库、授权台账、卖家白名单
  监测报告  — 按时间窗生成汇总报告


五点五、V1.1 新增功能
--------------------------------------------------------
  1) 图像指纹比对（盗图识别）
     位置：版权与授权 → 素材库（图片指纹）
     用法：上传官方海报/立绘 → 系统只保存 64 位感知哈希
           巡检时把商品主图哈希与素材库比对，相似度 ≥84% 触发规则 R009
     说明：只存哈希不存原图，避免二次分发他人素材

  2) 取证包导出
     位置：商品线索 → 点开任一线索 → 右下角「下载取证包」
     内容：snapshot.html（页面快照）、listing.json（原始数据）、
           README.txt（说明）、manifest.json（每个文件的 SHA-256）
     校验：PowerShell 执行 Get-FileHash .\snapshot.html -Algorithm SHA256
           与 manifest.json 中的值对比，一致说明未被改动

  3) 案件管理（卷宗）
     位置：左侧「案件管理」
     流程：待受理 → 调查中 → 已发函 → 渠道处理中 → 已结案 / 已驳回
     支持：关联多条线索、处置时间线、负责人、处置期限（逾期标红）
     入口：也可在「商品线索」详情页点「立案」，直接由线索建案

  4) 动态价格基线
     位置：作品维度自动计算，规则 R005 使用「低于 P20 基线」判定
     说明：比固定「低于均价 40%」更贴合不同区服/档位的价格分布，误报更少
六、数据与重置
--------------------------------------------------------
  数据库文件：data\app.db（首次启动自动生成）
  恢复初始演示数据：双击  重置演示数据.bat
    · 注意：重置会清空业务数据与账号，并重建默认管理员 admin

  想接入真实数据时，修改：
    server\services\crawler\jiaoyimao.mjs
    server\services\crawler\pangxie.mjs
  的 search() 实现即可，入库、匹配、评分、预警链路会自动复用。

七、判定规则
--------------------------------------------------------
  R001 未授权经销(40)  R002 私服外挂(45)  R003 账号租赁(20)
  R004 代充代练(15)    R005 异常低价(18)  R006 找回话术(35)
  R007 未收录作品(12)  R008 内部号(30)
  取最高 3 条求和封顶 100：≥70 高 ，≥40 中 ，其余低。
  权重可在 server\services\detection.mjs 中调整。

八、合规提醒
--------------------------------------------------------
  1. 只监测公开可见的交易页面，不绕过登录、不采集个人信息；
  2. 遵守渠道条款与 robots，正式使用建议走渠道 API 或数据合作；
  3. 系统输出为风险线索，不构成法律结论；
  4. 正式维权请以公证 / 可信时间戳固化的原始页面为证据。

  详见 docs\COMPLIANCE.md

十、常见问题
--------------------------------------------------------
  Q: 双击后提示"未检测到 Node.js"
  A: 安装 Node.js 22.5+（https://nodejs.org），装完重开命令行再试。

  Q: 忘记管理员密码
  A: 删除 data\app.db 后重新启动（会重建演示数据与默认账号），
     或在登录页注册新账号（首个新账号不会是管理员）。

  Q: 登录后刷新页面要求重新登录
  A: 浏览器禁用了 Cookie，请在站点设置中允许 Cookie。

  Q: 勾选了"记住账号密码"，下次打开还是要登录
  A: 检查三点：① 距上次登录是否已超过 7 天；② 浏览器是否清除了 Cookie；
     ③ 是否用了无痕/隐私窗口（无痕窗口关闭即清除）。

  Q: 端口 8787 被占用
  A: 关闭占用程序，或设置环境变量 PORT=其他端口后重新启动。

  Q: 页面空白
  A: 确认命令行窗口仍在运行，且浏览器地址是 http://127.0.0.1:8787

  Q: npm install 很慢 / 失败
  A: 切换国内镜像：npm config set registry https://registry.npmmirror.com
