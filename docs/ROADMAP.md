# 路线图 · V1.0 → V2.0

## V1.0（当前）· 可运行框架

- [x] 版权库 / 授权台账 / 卖家白名单
- [x] 双渠道适配器契约（交易猫、螃蟹）+ 演示数据
- [x] 作品匹配（别名、符号归一化、错别字容错）
- [x] 8 条风险规则 + 加权评分 + 处置建议
- [x] 线索库、预警队列、状态流转
- [x] 监测任务、立即巡检、巡检记录
- [x] 周期报告生成
- [x] 总览看板与 6 个前端页面
- [x] 单元测试（规则链 / 匹配器）

## V1.1 · 可运营化（1–2 周）

- [ ] **账号与 RBAC**：管理员 / 法务 / 运营 / 只读四角色，操作留痕
- [ ] **异步任务队列**：巡检改为 job 队列，支持并发、重试、断点续跑
- [ ] **批量处置**：勾选多条线索批量通知 / 下架 / 误报
- [ ] **导出能力**：线索 CSV、报告 PDF、下架通知函模板（DOCX）
- [ ] **通知集成**：Webhook / 企业微信 / 邮件，预警分级推送
- [ ] **数据保留策略**：快照按周期归档，附哈希校验

## V1.2 · 判定增强（2–4 周）

- [ ] **图像指纹**：商品主图 pHash + 素材库比对，识别盗图与私服截图
- [ ] **账号特征抽取**：从标题/描述结构化出区服、等级、保障类型
- [ ] **卖家聚类**：同主体多店铺关联，识别批量经销
- [ ] **价格基线**：按时段/区服动态计算均价，替代静态 40% 阈值
- [ ] **规则配置界面**：权重与阈值可视化调整，带灰度与回滚

## V1.3 · 取证与协同（1–2 月）

- [ ] **可信取证**：页面快照 + 时间戳/哈希存证，生成取证包
- [ ] **渠道工单对接**：通过渠道开放接口提交下架请求并回传结果
- [ ] **案件管理**：单案卷宗（线索 + 证据 + 往来函件 + 结论）
- [ ] **对接版权方**：按作品/地区分权，版权方自助查看本作品数据

## V2.0 · 平台化

- [ ] 多租户 SaaS 化，按作品/渠道计费
- [ ] 规则 Marketplace：行业共享关键词库与判定模板
- [ ] 数据湖 + BI：跨季度趋势、渠道治理效果评估
- [ ] 模型辅助（仅作召回补充，判定仍走可解释规则）
- [ ] 移动端只读看板与预警推送

## 非目标（明确不做）

- 不提供账号买卖、代充、代练等交易能力
- 不绕过登录/验证码抓取，不采集买家个人信息
- 不自动执行平台举报以外的施压行为
- 不替代律师意见与正式法律程序
