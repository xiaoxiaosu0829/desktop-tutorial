# 网络游戏账号交易版权监测系统 V1.1

> 面向游戏版权方 / 发行商 / 渠道合规团队的**账号交易侵权线索监测与处置平台**。
> 已接入交易猫、螃蟹、淘手游、5173、7881 五个渠道，按账号交易平台的信息结构建模：把「挂售商品 → 作品归属 → 授权资质 → 风险判定 → 处置闭环 → 周期报告」串成一条可审计的流水线。

本仓库是 **V1.1 可运行框架**：后端 API、数据库、监测引擎、风险规则链、图像指纹、取证包、案件卷宗、前端控制台全部打通，开箱即可演示；数据为**合成演示数据**，真实渠道接入点已留出。

---

## 一、这个系统解决什么问题

游戏账号交易天然带有版权与合同风险：账号内的虚拟资产归属版权方，未经授权的规模化经销、私服资源、找回骗局都会侵蚀正版生态。人工巡检无法覆盖海量挂售，且缺少可追溯的处置证据链。

系统把这件事拆成五步：

| 步骤 | 系统能力 |
| --- | --- |
| 1. 发现 | 按关键词 + 渠道周期巡检，抓取**公开可见**的挂售快照 |
| 2. 归属 | 标题归一化后匹配版权库（作品名 / 别名 / 错别字容错） |
| 3. 判定 | 9 条可解释规则打分（未授权经销、私服外挂、盗用素材图、找回话术…） |
| 4. 处置 | 预警队列 → 立案 → 通知下架 → 结案 / 误报，取证包可导出 |
| 5. 输出 | 周期报告、单案报告、下架通知函底稿 |

## 二、功能矩阵（V1.1）

- **总览看板**：线索总量、高风险数、待处理预警、未结案件、图片命中数、处置率、7 日趋势、风险构成、作品排行、最新预警
- **商品线索**：多条件筛选（关键词 / 渠道 / 等级 / 状态）、分页、详情抽屉（规则命中 + 图片比对 + 建议 + 原始快照）、一键立案、一键下载取证包
- **风险预警**：按「新建 → 处理中 → 已处理 / 误报」推进，支持批量状态流转
- **案件管理（V1.1）**：卷宗式案件（编号 / 优先级 / 负责人 / 处置期限）、状态机「待受理 → 调查中 → 已发函 → 渠道处理中 → 已结案 / 已驳回」、关联线索、处置时间线、逾期标记
- **图像指纹（V1.1）**：素材库上传官方图 → 计算 64 位 pHash（只存哈希不存原图）→ 商品主图比对，相似度 ≥84% 自动计入 R009
- **取证包（V1.1）**：一键导出 ZIP（页面快照 HTML + 原始数据 JSON + SHA-256 清单 + 说明），可用于内部复核与对外沟通
- **监测任务**：任务增删改停、关键词多组、间隔配置、立即巡检、巡检记录（可审计日志）
- **版权与授权**：作品版权库、授权台账、卖家白名单；授权变更自动触发全量线索重算
- **动态价格基线（V1.1）**：按作品统计 P20 / P50 / P80，用「低于 P20」替代固定「均价 40%」阈值，可一键重算
- **监测报告**：按时间窗生成，含概览、渠道构成、作品分布、高频规则
- **账号与登录**：注册 / 登录 / 退出；右上角账号区显示当前用户与免登录剩余天数；密码 scrypt 加盐派生；默认会话级登录（关浏览器即失效），勾选「记住账号密码」可 7 天免登录，到期自动失效

## 三、快速开始

**Windows 一键启动（推荐给非开发同学）**

1. 安装 Node.js 22.5+（https://nodejs.org）
2. 双击 `启动.bat`：自动安装依赖 → 启动服务 → 打开 http://127.0.0.1:8787
3. 其他脚本：`开发模式.bat`（前端热更新）、`重置演示数据.bat`（重建演示库）
4. 详细图文说明见 `使用说明.txt`

> 首次打开会先进入**登录页**。默认管理员账号 `admin` / `Admin@12345`，也可以在注册页自助创建账号（首个注册账号自动成为管理员）。
>
> 登录策略：默认是**会话级登录**（关闭浏览器即失效，符合"每次进入都要登录"）；登录页勾选「记住账号密码」后为 **7 天免登录**，超过 7 天未登录则自动失效，需重新输入账号密码。

**命令行方式**

```bash
# 1. 安装依赖（Node ≥ 22.5，内置 node:sqlite）
pnpm install        # 或 npm install

# 2. 开发模式：API:8787 + 前端:5173
pnpm dev

# 3. 生产模式：构建前端后由 API 直接托管
pnpm build
pnpm start          # http://127.0.0.1:8787
```

首次启动会自动建库并写入演示数据；重建数据：

```bash
pnpm seed           # 等价于 node server/seed.mjs --reset
```

单元测试（规则链 + 作品匹配）：

```bash
pnpm test
```

> 若使用 npm 且 PowerShell 禁止脚本，请改用 `npm.cmd` 或 `node node_modules/...` 直接调用。

## 五、风险规则链（V1.1）

| 规则 | 名称 | 权重 | 判定依据 |
| --- | --- | --- | --- |
| R001 | 未授权经销他人作品账号 | 40 | 作品在版权库，卖家不在授权台账 |
| R002 | 涉及私服 / 破解 / 外挂 | 45 | 私服、破解、外挂、修改器等话术 |
| R003 | 账号租赁 / 共享 | 20 | 租号、共享号、按天租 |
| R004 | 代充 / 代练 / 返利 | 15 | 代充、代练、折扣充值 |
| R005 | 异常低价 | 18 | 低于作品价格基线 P20（无基线时退回均价 40%） |
| R006 | 找回 / 解绑话术 | 35 | 包找回、解绑实名、包赔 |
| R007 | 未收录作品疑似侵权 | 12 | 未命中版权库但含交易特征 |
| R008 | 官方内部号 / 内部渠道 | 30 | 内部号、渠道号、福利号 |
| R009 | 盗用版权方素材图 | 35 | 商品主图与素材库 pHash 相似度 ≥84% |

**评分**：取权重最高的 3 条规则求和并封顶 100；`≥70 高`、`≥40 中`、其余为低。所有规则命中均记录原文片段，保证可解释、可申诉。

## 七、演示数据 vs 真实接入

- 当前所有商品、卖家、店铺 ID、链接均为**合成数据**，域名使用 `.invalid` 保留域，不指向任何真实站点。
- 五个渠道适配器均处于 demo 模式：search() 返回合成样本，不发起网络请求。
- 真实接入时替换 `crawler/<source>.mjs` 的 `search()` 实现即可，契约保持 `{ externalId, title, description, price, sellerName, url, postedAgoMin }`。限速器、去重、入库、评分、预警全部复用。

## 八、合规边界（务必先读）

1. **只采集公开可见信息**：不绕过登录/验证码，不抓取买家个人信息，不接触账号凭据。
2. **遵守渠道条款与 robots**：默认 1.2s/请求、单次最多 3 页；正式使用应申请渠道 API 或数据合作授权。
3. **数据最小化**：只保留取证所必需的页面快照与标题，卖家标识做脱敏占位。
4. **可申诉**：每条预警携带规则编号与命中原文，支持标记误报并回滚状态。
5. **报告不替代法律取证**：正式维权材料应以公证/可信时间戳固化的原始页面为准。

详见 [docs/COMPLIANCE.md](docs/COMPLIANCE.md)。

## 九、已知边界（V1.1 仍未做）

- 不做真实登录态抓取、不做验证码识别、不做自动化举报提交
- 认证只有「管理员 / 成员」两种角色，未做细粒度权限与操作审计导出（规划于 V1.2）
- 图像比对只做「整图 pHash」，不含局部裁剪/拼接/水印去除的鲁棒识别（规划于 V1.2）
- 不含多租户、RBAC、审计日志导出（规划于 V1.1 / V2.0）
- 调度器为进程内 60s 轮询，未接入分布式队列
